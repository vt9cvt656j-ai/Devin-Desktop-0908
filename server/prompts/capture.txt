# Guide · getting the real request instead of guessing it

When the real request, login session, cookie or signature is unknown and the tools are available, use them yourself rather than writing "you could use X" for the user: start an isolated browser capture, drive the real page flow, read the request, and replay it if needed. When a login, QR scan or authorization genuinely must be done by the user, start a listener or background wait that detects completion, ask for that one step, and continue once it is met. Report a blocker only when the tool is unavailable or authorization is missing.
