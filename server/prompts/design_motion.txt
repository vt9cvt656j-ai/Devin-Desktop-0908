# michael-design motion layer: pick the smallest tool, then retrieve the recipe

**Get the recipe from the corpus, not from memory.** `knowledge_search(domain="michael-design")` carries effect-named blueprints with real durations, easing, mobile rules and fallbacks, plus a library catalogue with licences. Search the effect the user named — Chinese effect names hit directly.

## Order of preference

1. **Browser-native, zero dependency**: View Transitions for route and shared-element morphs; scroll-driven animations (`animation-timeline: scroll()/view()`) for progress, reveals, parallax; `@starting-style` for `popover`/`dialog` entrances. Ship inside `@supports`, static layout as fallback.
2. **Tailwind projects**: `tw-animate-css` utilities and `data-[state=open]` variants — what shadcn/ui ships on v4. Never add the unmaintained `tailwindcss-animate`.
3. **Component motion**: Motion (npm `motion`, ex-Framer Motion) — `whileInView`, `AnimatePresence`, `layout`/`layoutId`, gestures. `motion-v` for Vue.
4. **Timeline and scroll choreography**: GSAP + ScrollTrigger, all plugins now free commercially; `useGSAP()` in React so tweens revert. Lenis for smooth scroll, driven from `gsap.ticker`.
5. **3D**: React Three Fiber + drei, with a performance budget, loading state and fallback.
6. **Single-purpose helpers** beat hand-rolling for lists, counters, toasts, sheets, carousels and confetti — the corpus names the current pick for each.

**Licence check before copying a component.** Magic UI and Motion Primitives are MIT. React Bits and animate-ui carry a Commons Clause forbidding redistribution — never emit their source into a user's project; reimplement against the project's own tokens.

## Compose, do not pile up

One signature moment + reusable section reveals + micro-interaction feedback. Never a scrub-pinned story, parallax, tilt, marquee and particles on one page. One easing (`cubic-bezier(0.16,1,0.3,1)`), one scale: 120ms feedback, 200ms transitions, 300–500ms entrances.

Every effect ships three things or it does not ship: a mobile story (drop pin/parallax/tilt/autoplay below 768px, reveal ~12px), a `prefers-reduced-motion` fallback keeping the information and dropping the movement, and a keyboard/assistive path — split text keeps its `aria-label`, hover-only effects are never the sole affordance, anything autoplaying can be paused.
